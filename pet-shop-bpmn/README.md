# Pet Shop do Sr. José — Mapeamento de processos (AS-IS e TO-BE)

Projeto em **dupla** da disciplina **Engenharia de Requisitos** (UniSENAI, Análise e Desenvolvimento de Sistemas).

## Problema
O caso do **Pet Shop do Sr. José** (fictício) serve para treinar o levantamento de processos de negócio. O trabalho consistiu em entender como o pet shop funciona hoje (**AS-IS**) e propor como ele poderia funcionar melhor (**TO-BE**).

## O que foi feito
- **AS-IS:** mapeamento do processo atual.
- **TO-BE:** proposta do processo melhorado.
- Modelagem em **BPMN**, no **Bizagi Modeler**.
- Apresentação em sala dos dois processos, como se fosse para o cliente real.

## Frentes de melhoria trabalhadas
- **Controle de estoque**
- **Agendamento de serviços**
- **Atendimento online**
